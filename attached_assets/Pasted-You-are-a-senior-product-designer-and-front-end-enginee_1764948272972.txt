You are a senior product designer and front-end engineer.

Build a **production-ready, fully responsive marketing website** for a brand called **HighBeam**.

## Tech stack

- Use **React + Vite + Tailwind CSS**.
- Organize components cleanly (e.g., `components/`, `sections/`, `pages/`).
- Use functional components with hooks.
- Make the layout responsive for mobile, tablet, and desktop.

Assume I have a logo file named `highbeam-logo.svg`.

---

## Brand & Visual Direction

HighBeam is a **premium experiential tech studio** that builds interactive and immersive digital experiences for events and activations.

### Overall vibe

- Premium but fun  
- Futuristic and creative  
- Clean, minimal, high contrast  
- Feels like an experiential / interactive studio, not a corporate agency

### Theme

- **Dark mode as the base**.

### Colors

Use these as Tailwind custom colors:

- `hb-black`: `#0A0A0A` (page background)
- `hb-gray`: `#1A1A1A` (cards, surfaces)
- `hb-yellow`: `#FFD300` (primary accent / CTA)
- `hb-white`: `#F2F2F2` (text on dark)
- Optional subtle blue for tiny accents: `#4D8FFF`

Use yellow **sparingly but strongly** for CTAs, highlights, dividers, and hover accents.

### Typography

Use **Google Fonts**:

- Headings: **Space Grotesk**, bold, slightly futuristic.
- Body: **Inter**, regular/medium.

Large, bold headings. Lots of breathing room. Align typography with the strong geometric character of the logo.

---

## Layout & Navigation

Make it a **single-page site** with top navigation that scrolls smoothly to sections:

- Home
- Capabilities
- Work
- Process
- About
- For Agencies
- Contact

Sticky navbar on desktop, simple menu on mobile (hamburger that opens a full-screen or panel menu).

---

## Interactions & Motion

- Smooth scroll to sections.
- On hover, cards lift slightly (`translateY`, `shadow`) and yellow accent appears.
- Buttons: subtle scale-up and glow on hover.
- Use **subtle diagonal / beam-inspired accents** (e.g., background gradients or section dividers with angled edges inspired by the logo).
- Page load: simple fade-in + slight upward motion for hero content (no heavy animations).

Keep animations smooth and fast (~200–300ms).

## GENERAL UX REQUIREMENTS

- Use a **max-width container** and generous padding; nothing should feel cramped.
- Maintain consistent spacing scale (e.g., Tailwind `space-y` / `gap`).
- Make sure text contrast meets accessibility guidelines.
- Support both desktop and mobile navigation elegantly.
- The site should feel like a **modern, premium studio** website, not a generic template.

Deliver clean, well-structured code with clear component names so it’s easy to extend later.
